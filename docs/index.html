GitHub 回復バッジ GitHub Recovery Badge

フリーメール等が原因のアカウント制限（サードパーティログイン拒否・シャドウバン）から 回復したことを、GitHub ログインで本人確認しながら証明するバッジ。 フォークもトークンも不要です。

A badge that proves your account has recovered from a GitHub account restriction (third-party login denied / shadowban, e.g. caused by a free-mail address), with identity verified by your GitHub login. No fork, no token required.

STEP 1 — 登録（GitHub ログインが必要） STEP 1 — Register (GitHub login required)

ボタンを押して Issue を送るだけ Just press the button and submit an Issue

Issue の作成には GitHub ログインが必須です。採番 Bot は、あなたが入力した文字ではなく GitHub が検証した本人のログイン名だけを使って登録します。 だから他人になりすまして番号を取ることはできません。

Opening an Issue requires being logged in to GitHub. The numbering bot ignores anything you type and registers only the login name verified by GitHub, so nobody can claim a number on someone else's behalf.

  1. 下のボタンで登録 Issue を開く（ログイン状態で送信）
  2. Bot が数十秒であなた専用のバッジ Markdown と通し番号をコメント
  3. Bot は登録前に github.com/あなた が実際に見える状態か（＝本当に回復済みか）を確認します
  1. Open the registration Issue with the button below (submit while logged in)
  2. Within seconds, the bot comments with your personal badge Markdown and serial number
  3. Before registering, the bot checks that github.com/you is publicly visible (i.e. you have really recovered)
GitHub で登録する → Register with GitHub →

STEP 2 — 貼る STEP 2 — Paste

Bot が返したバッジを README やブログへ Put the badge from the bot in your README or blog

渡されるバッジは shields.io が github.com/あなた を直接見て判定します。 トークン不要・自己申告なしで、閲覧するたびにリアルタイム検証。制限が再発すれば 自動で赤 restricted に戻り、回復していれば緑 unrestricted。

shields.io checks github.com/you directly to render the badge — no token, no self-reporting, verified live on every view. Green unrestricted while recovered; it turns red restricted automatically if the restriction comes back.
